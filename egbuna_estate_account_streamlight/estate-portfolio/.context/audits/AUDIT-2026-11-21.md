# EPM v2 — Baseline Audit, 2026-11-21

**Scope.** This audit is read-only. It compares the repository, the running server and the production DB against `original_intent/*`, `.context/MASTER_CONTEXT.md` and `.context/feature-specs/*`.
**Working tree.** `/home/zubbyik/openagile_2/egbuna_estate_account_streamlight/estate-portfolio`, branch `test` @ `893c63bf8e5afd70f1193b6522327095402069d7`
**origin/main.** `0415599514a32773482dba2c40fd26deb8c46e3c`. Confirmed live with `git ls-remote`. The last local fetch was 2026-11-07, but the remote refs match.
**Baseline-doc location note.** `original_intent/` is **not** inside the EPM directory. It lives one level up at `egbuna_estate_account_streamlight/original_intent/`, last touched 2026-06-15. `Architecture_spec.md` is **byte-identical to `FOUNDATION_VISION.md`** (`cmp` → IDENTICAL), so no architecture spec actually exists in the original intent.
**MASTER_CONTEXT version.** Working tree / `test` = **v4.10 (2026-08-15)**. That v4.10 **is NOT merged to main**: `origin/main` still carries **v4.2 (2026-07-06)**. v4.10 is also on `chore/f-td-001-reconcile` (commit `d1ba21ad…`, PR #9 open). The untracked `.context/MASTER_CONTEXT-v4.10-Update_package.md` has already been applied to the `test` copy.

### Actions deliberately NOT taken (read-only rules)
- **Integration tests not run.** `backend/tests/integration/conftest.py` runs `Base.metadata.create_all` (DDL) against `epm_test` in a session-scoped autouse fixture, which the "no DDL" rule forbids. Only the backend **unit** tier (no DB) and the frontend vitest suite were run, with `-p no:cacheprovider` and `PYTHONDONTWRITEBYTECODE=1`.
- **No `docker exec` into the EPM app container, and no HTTP requests to testdrive.** Running-code state was inferred from `docker inspect`, `docker image history`, `docker diff` and `docker logs` only.
- **psql use.** Only `SELECT` and `\d` were run, through `docker exec openagile_postgres psql` with `PGOPTIONS=-c default_transaction_read_only=on` (confirmed `on`).
- **Secrets.** All secret values are masked. Equality checks were done by comparing sha256 prefixes in-process; no hash or value was printed.
