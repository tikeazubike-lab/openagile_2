# Phase 0 — Idea Capture

**Goal**: turn a rough idea into a one-page brief that Phase 1 can build on. No documents are
version-controlled yet — this is a scratch conversation.

## Questions to ask (2–3 at a time)

Round 1:
1. In one sentence, what does this project do?
2. Who is it for — just you, a small team, or public users?

Round 2:
3. What's the single most important thing it must do well? (pick one, not a list)
4. Is there an existing project you're replacing or self-hosting an alternative to?

Round 3:
5. Rough tech leaning already? (e.g. "definitely Docker Compose", "no idea yet", "must be Python")
6. Timeline pressure — side project pace, or need something working soon?

## Output

Do **not** write a file yet. Summarize the answers back to the user in 4–6 lines and ask:
"Does this capture it? Ready to move into Phase 1 — Project Foundation, where we'll turn this
into `.context/project-overview.md`?"

## Checklist before moving to Phase 1

- [ ] One-sentence purpose confirmed
- [ ] Primary user identified
- [ ] One non-negotiable quality attribute identified (not a wishlist)
- [ ] User has confirmed the summary is accurate
